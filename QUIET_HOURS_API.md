# Тихие часы специалиста

Если клиент пишет специалисту вне его рабочего времени по графику, пуши
чата специалисту не приходят. Когда начинается смена, приходит одна сводка:

> **Пока вас не было**
> Оформлено тарифов: 2. Непрочитанных сообщений: 5 от 3 клиентов.

Специалист может выключить тишину настройкой «Получать уведомления всегда».

## Как устроено

- Пуши чата шлёт Stream, придержать их он не умеет. Поэтому вне графика бэк
  выключает специалисту пуши чата в Stream (push preferences,
  `disabled_until` = начало следующей смены). Сообщения в чат приходят как
  обычно, без пуша.
- Планировщик (сервис `scheduler`, `manage.py sync_quiet_hours --every 120`)
  раз в 2 минуты сверяет график. С началом смены пуши включаются обратно, и
  бэк шлёт сводку обычным уведомлением (FCM + лента, `type:
  quiet_hours_summary`, `source: profichat`). Нечего сообщить — сводки нет.
- Рабочее время считается так же, как в приложении: смена через полночь
  кончается на следующий день, круглосуточный день — от полуночи до полуночи,
  выходной, нерабочая дата и день без записи в графике — не работает. Обед —
  рабочее время. Специалист без графика тишины не получает. Если смен нет
  в ближайшие 14 дней (отпуск), тишина не включается.
- Звонки приложение и так даёт только в рабочее время специалиста.

## Настройка «Получать уведомления всегда»

```
GET   /api/users/me/notify-outside-work-hours/
PATCH /api/users/me/notify-outside-work-hours/
{ "notifyOutsideWorkHours": true }
```

Ответ — `{ "notifyOutsideWorkHours": true }`. По умолчанию `false` (тишина
включена). Поле есть и в `GET /api/users/me/`.

Применяется сразу, не дожидаясь планировщика: включили «всегда» посреди
ночи — пуши пошли сразу (без сводки); выключили — тишина начинается тут же.

## Уведомление-сводка

`type: quiet_hours_summary`, `source: profichat`, заголовок «Пока вас не
было», текст — готовая строка на русском. Отдельного экрана нет: тап можно
вести в список чатов.

## Тариф, оплаченный вне графика

Клиент может оформить тариф в любое время, но срок тарифа считается от
момента, когда специалист начнёт отвечать. Оплатили в 23:00 тариф на сутки
при графике 9–18 — писать можно сразу, а сутки идут с 09:00 следующего дня
(`activated_at` = момент оплаты, `expires_at` = начало смены + срок). В смену
и у специалиста без графика всё как раньше: срок от момента оплаты. Доступ,
который специалист выдаёт сам по приглашению, не сдвигается.

`POST /api/access-orders/` в ответе (и для бесплатного, и для платного
тарифа) отдаёт `availableFrom` — начало следующей смены, если специалист
сейчас вне графика, иначе `null`. Приложение показывает перед оплатой:
«Специалист сейчас не работает и ответит завтра в 09:00 — время тарифа
начнёт идти с этого момента».
