# Push из ErkinAI

`POST /api/integration/erkinai/push/`

ErkinAI просит Profigram доставить push-уведомление своему пользователю.
Обратное направление интеграции: обычно Profigram ходит в ErkinAI, здесь —
наоборот. Используется каналом «Пуш в ProfiChat» в конструкторе автоматизаций
ErkinAI.

## Авторизация

```
X-Api-Key: <MEDCRM_API_KEY>
```

Тот же ключ, что и у легаси-эндпоинтов `/api/integration/medcrm/`. Переменная
окружения сохранила историческое имя: переименование сломало бы развёртывание.

## Тело запроса

```json
{
  "phone_number": "+996700123456",
  "title": "Запись подтверждена",
  "body": "Здравствуйте, Айжан! Ждём вас завтра в 10:00.",
  "payload": {"appointment_id": "42"},
  "external_id": "automation-job-1024"
}
```

| Поле           | Обязательно | Описание                                                        |
| -------------- | ----------- | --------------------------------------------------------------- |
| `phone_number` | да          | Номер получателя. Разделители чистятся, `+` не обязателен        |
| `title`        | да          | Заголовок — первая строка в шторке телефона                      |
| `body`         | да          | Текст уведомления                                                |
| `payload`      | нет         | Доп. данные. Уходят в FCM `data`, значения приводятся к строкам   |
| `external_id`  | нет         | Идентификатор отправки на стороне ErkinAI, см. «Повторы»           |

## Ответ — `200 OK`

```json
{
  "notificationId": 512,
  "delivered": true,
  "deviceCount": 2,
  "successCount": 1,
  "errorCode": "",
  "errorMessage": "",
  "duplicate": false
}
```

| Поле             | Описание                                                          |
| ---------------- | ------------------------------------------------------------------ |
| `notificationId` | Id записи в ленте уведомлений пользователя                          |
| `delivered`      | Push принят FCM хотя бы одним устройством                           |
| `deviceCount`    | Сколько активных устройств было у пользователя                      |
| `successCount`   | На сколько из них push ушёл                                         |
| `errorCode`      | Код ошибки FCM, см. `PUSH_STATUS_API.md`, либо `NO_DEVICES`         |
| `duplicate`      | Запрос отброшен как повтор по `external_id`                         |

**`200` не означает доставку.** Уведомление в ленте создаётся всегда, а push
может не уйти: у пользователя нет устройства, протух FCM-токен, отказал FCM.
Смотрите `delivered` и `errorCode`, а не только HTTP-статус.

## Повторы

Если ответ не дошёл до ErkinAI, отправка у неё остаётся неподтверждённой, а у
нас — выполненной. Повтор с тем же `external_id` возвращает уже созданное
уведомление с `duplicate: true` и **не шлёт второй push**: иначе пользователь
получил бы дубль в шторке.

Без `external_id` дедупликации нет — каждый запрос создаёт новое уведомление.

## Ошибки

| Код | Тело                                                                            | Причина                          |
| --- | -------------------------------------------------------------------------------- | -------------------------------- |
| 400 | `{"code": "VALIDATION_ERROR", "errors": {"title": ["Обязательное поле."]}}`      | Не передано обязательное поле    |
| 401 | `{"detail": "Неверный API-ключ."}`                                               | Неверный или отсутствует ключ    |
| 404 | `{"code": "USER_NOT_FOUND", "message": "Пользователь ProfiChat с таким номером не найден."}` | Нет аккаунта с таким номером |

Аккаунт по запросу **не создаётся**: ErkinAI не может завести пользователя
Profigram, отправив ему push.
