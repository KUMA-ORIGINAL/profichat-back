# Образование и места работы специалиста

Профиль читается и обновляется прежним endpoint:

- `GET /api/users/me/`
- `PATCH /api/users/me/`

Тот же формат используется при создании анкеты специалиста через
`POST /api/apply/`; поле мест работы там называется `workExperiences`.

Поля `education` и `workExperience` теперь являются списками. Middleware проекта
преобразует camelCase клиента в snake_case сериализаторов и обратно.

```json
{
  "education": [
    {
      "institution": "БГУ",
      "faculty": "Юридический",
      "startDate": "2018-09-01",
      "endDate": "2022-06-30"
    }
  ],
  "workExperience": [
    {
      "organization": "МЦ Мама Доктор",
      "position": "Ортодонт",
      "startDate": "2022-07-01",
      "endDate": null,
      "isCurrent": true
    }
  ]
}
```

Даты передаются в ISO-формате `YYYY-MM-DD`. Для завершённого места работы
`endDate` обязателен. Если `isCurrent` равен `true`, `endDate` должен быть
`null`. Дата окончания не может быть раньше даты начала.

При `PATCH` переданный список полностью заменяет старый. Пустой список удаляет
все записи, а отсутствующее поле оставляет соответствующий список без изменений.
Те же структуры возвращаются в списке и карточке специалиста.
